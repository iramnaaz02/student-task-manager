# 🎓 Student Task Manager

A simple and user-friendly web application designed to help college students organize and manage their academic tasks, deadlines, and priorities.

## 📌 Problem Statement

College students often have to manage multiple assignments, lab work, projects, exams, and deadlines. Keeping track of all these tasks can become difficult and may lead to missed deadlines.

## 💡 Solution

Student Task Manager provides a simple platform where students can add, manage, search, filter, and complete their academic tasks from one place.

## ✨ Features

- Add new academic tasks
- Add subject and deadline
- Set task priority
- Mark tasks as completed
- Delete tasks
- Search tasks
- Filter tasks by status
- Dashboard with task statistics
- Deadline warnings
- Tasks remain saved after refreshing the browser
- Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser LocalStorage
- Git
- GitHub

## ⚙️ How It Works

1. Enter the task name.
2. Enter the subject.
3. Select the deadline.
4. Select the priority.
5. Click "Add Task".
6. Manage the task using Complete or Delete.
7. Use search and filters to find tasks quickly.

## 💾 Data Storage

The application uses browser LocalStorage to save tasks.

This allows tasks to remain available even after refreshing the browser.
